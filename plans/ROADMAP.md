# zdos roadmap

Short index of what's built and what's next. **Keep this current** — add an entry when a
milestone/phase lands or a goal changes. Detailed plans live in `plans/`; session memory in
`.claude/.../memory/`.

## Now working
Real-mode 386 + DOS/BIOS core runs real BC3.1/TC++ programs deterministically. A full
**debugger** drives it: in-process control core + an **HTTP/JSON API** (breakpoints, step,
run-to-cycle, inspect/patch CPU+memory, **keyboard/mouse injection**, console read), with
in-process *and* black-box (real-binary-over-HTTP) test suites.

## Timeline (done)

2. **DOS oracle loop** — DOS API complete (43-program BC3.1 corpus) + 4 I/O oracle modalities (VGA mode 13h, keyboard, mouse, sound). → `[[dos-oracle-loop]]`, `plans/dos-oracle-report.md`
3. **Real toolchain on zdos** — TC++ 1.0 compiles→links→runs end-to-end, byte-deterministic. → `[[real-toolchain-on-zdos]]`
4. **Debugger M1 — control core** (breakpoints: exec/cycle/interrupt/memory-watchpoint, step/run-to, side-effect-free inspect, mutate; cycle-neutral). Audited PASS. → `plans/debugger-milestone-1.md`
5. **Debugger M2 — HTTP/JSON API** (~21 endpoints over the core; one-command-in-flight worker, determinism-preserving). Audited PASS. → `plans/debugger-milestone-2.md`
6. **Black-box test harness** (Zig `Session`, spawns the real binary, drives HTTP).
7. **Input injection** (design v3): keyboard polling+blocking (8042 → IRQ1 → INT 09h → BDA ring → INT 16h) + mouse polling (INT 33h) over the API, deterministic; bridge primitives (`runGuestFarCall`, poll-loop emitter); black-box **KEYECHO.EXE** echo+ESC test. Bonus: INT 08h→INT 1Ch timer chaining fixed. → `plans/input-injection.md`, `[[input-injection]]`
8. **VGA 0x3DA Input Status Register #1** — deterministic, cycle-derived vertical-retrace (bit 3) + display-enable (bit 0) status (0x3DA / 0x3BA), integer-only `f(cpu.st.cycles)`, no host clock/float. Unblocks retrace-polling guests (Borland `putch` snow-avoid, mode-13h vsync) that previously spun on the unmapped 0xFF. Excluded from cross-emulator goldens (oracle-non-determinism boundary). → `plans/vga-retrace.md`.
9. **VGA text-mode video (B8000/B0000) + INT 10h text services + `GET /api/screen`** — the text page is backed as guest-RAM-like MMIO (color B8000 / mono B0000, two 32 KiB slabs, `getHostPtr` fast path + `peek8`); INT 10h text services (AH=00 text mode-set, 01/03 cursor shape, 06/07 scroll, 08 read-char, 09/0A write-char, 0E teletype, 13 write-string) are deterministic host traps over the BDA + text page (BDA-width, `useattr=false` attr-preserve, cursor-attr scroll fill, 0x0720 word fill, BEL silent no-op — no host clock, no cursor blink). A side-effect-free `GET /api/screen` renders the BDA active page as a char grid (+ optional `?attrs=1`). **Acceptance gate PASSED:** KEYECHO with real Borland `putch()` (direct B800 video) is now observable on `/api/screen` (ESC terminates ret 0). → `plans/text-mode-video.md`.
10. **Full VGA build — Phase 1 (register files) + Phase 2 (BIOS/config layer)** — Phase 1: SEQ/CRTC/GC/AC indexed POD register files with full read-back + AC flip-flop + write-protect, reachable via guest IN/OUT (0x3C0/1, 0x3C4/5, 0x3CE/F, 0x3D4/5), snapshot-covered. Phase 2: the BIOS/config layer per `plans/vga-spec/04-modes-int10-bda.md` — **set-mode (AH=00) rewritten as the full IBM VGA BIOS register dump** (per-mode SEQ/CRTC/GC/AC/misc tables in `src/bios/vga_modes.zig`, copied verbatim from spice86 `RegisterValueSet.cs`; default DAC palettes in `src/bios/vga_palettes.zig`; 8×8/8×14/8×16 ROM fonts in `src/bios/vga_font.zig`, copied verbatim from dosbox-staging `int10_memory.cpp`), driven through the port path so BIOS set-mode and a raw-port guest are byte-identical; default DAC palette loaded unconditionally with the AC-internal-palette gated on MODESET_CTL 0x89 bit 3 (fix S3); mode-13h CRTC[9]=0x41 dumped verbatim (fix S1). New INT 10h subfns: **AH=1A00/1A01** (Display Combination Code, returns BL=0x08 = LAMUT adapter-detect), **AH=1130** (get-font-pointer, returns real ES:BP to staged ROM 8×8 — LAMUT W1b). BDA gaps filled (CURRENT_START 0x4E, CURRENT_MSR 0x65, CURRENT_PAL 0x66, SWITCHES 0x88, MODESET_CTL 0x89=0x51 default, VS_POINTER 0xA8); fonts staged into BIOS ROM image at POST with IVT[0x1F]/[0x43] vectors. All three new files added to the determinism grep-gate (R1). Text-mode services (Phase #9) preserved. → `plans/vga-spec/`.

10c. **Full VGA build — Phase 5c (complete INT 10h set + save-pointer ROM chain)** — the remaining INT 10h subfns, all driven through the SAME port path as a raw-port guest (byte-identical): **AH=04** (light pen → AX=0), **AH=05** (set active page → BDA CURRENT_PAGE/START + CRTC 0x0C/0x0D start-address page-flip + cursor move; VRAM-ratio text 2 / planar 4 / 256 1), **AH=10 full** (AL=00/01/02/03/07/08/09 AC-palette set/get/overscan/blink via the 0x3C0 flip-flop with the spice86 save-index/restore sequence; AL=13 DAC color page; AL=18/19 PEL mask; AL=1A color-page state; AL=1B integer gray-scale summing — no float), **AH=11 full** (AL=00/01/02/04/10/11/12/14 font load — BDA CHAR_HEIGHT/NB_ROWS + CRTC max-scan-line; plane-2 glyph upload not text-render-observable per D-TM1 and flagged; AL=03 SEQ reg 3; AL=20-24 INT 1F/43 vectors + rows; AL=30 unchanged), **AH=12** (BL=10 EGA info, 30 scan lines, 31/33/34 BDA toggles, 32 video addressing, 36 SEQ reg1 bit5 screen on/off, 20/35 stubs; unknown BL = no-op), **AH=1B** (functionality/state info → 64-byte block: static-func far ptr + 30-byte BDA copy + DCC + color/page/scan-line/misc/256K). **Save-pointer ROM chain** (`src/bios/vga_rom.zig`, in the grep-gate): video parameter table + DCC table (count 0x10/ver 1/max 8 + 16 codes) + static-functionality table (dosbox bytes) + the 7-dword video-save-pointer table, staged into the BIOS image at POST; IVT[0x1D] + BDA VS_POINTER 0x40:00A8 pointed at them (closes the Phase-2 deferral). AH=1C save/restore deferred (LOUD flag; spice86 omits it); AH=4F VESA stays the loud flag (out of scope). 13 new full-machine tests. → `plans/vga-spec/04-modes-int10-bda.md`.
11. **Full VGA build — Phase 4 (rasterizer + `GET /api/framebuffer`)** — a PURE whole-frame rasterizer `src/devices/vga_render.zig` (const `*Vga`, no draw loop, no host clock/float, in the devices grep-gate per R1): `render256Linear` (mode 13h, `vram[off]`), `render256Planar` (Mode-X de-interleave `plane=x&3, addr=start+y*stride+(x>>2)`, reads the plane-major slab directly — no latch load), `renderText` (ROM-font glyph + AC attribute pipeline, blink-high + solid cursor, §6), `renderEga`, `renderCga`. Attribute pipeline with the S2 fix (Color-Plane-Enable masks the 4-bit index before the AC lookup); 256-color modes bypass the AC; DAC 6→8 = `(c<<2)|(c>>4)` (pinned) + pel-mask; Max-Scan-Line row-repeat from bits 0-4+1 (S1, double-scan recorded as a flag not applied). Output = index image (oracle surface) + derived RGBA. Capture is a side-effect-free `Controller.framebuffer` peek (cycle-neutral; no DAC-index/AC-flip-flop/latch/field mutation — snapshot byte-identical, R3/R6); the text path reads the real staged ROM-font bytes from BIOS ROM space (`debug` now imports `bios`/`devices`). **[B1] transport:** a server-owned fixed render buffer (`index[640*480]` + `rgba[640*480*4]`, ~1.5 MiB) allocated once at server `init`, reached by the worker via `*RenderBuffers` (the Command stays pointer-free); `GET /api/framebuffer?format=index|rgba` streams the selected buffer as a raw `application/octet-stream` body with `X-Frame-Width/Height/Kind/Format` headers (pixels never route through `resp_buf`/JSON); an unsupported mode → 501 (no fake frame). PNG stays host-side. Tests: mode-13h + Mode-X capture round-trips, DAC 6→8, cycle-neutrality/purity, two-run byte-identity, text-glyph render, and the `/api/framebuffer` HTTP integration test. → `plans/vga-spec/03-crtc-scanout-render.md`.
12. **LAMUT.EXE end-to-end milestone (Phase 5d) — BOTH STAGES LANDED** (the v1 BaK VGA acceptance target). The full VGA build (#10/#10c/#11) closed every predicted hole; the acceptance probe needed **no further emulator changes** — pure verification. **Stage 1 (`LAMUT-OK`):** LAMUT.EXE (its real Vmcode.ovl VGA driver overlay run as guest code: adapter-detect → driver load → 100-entry vtable copy → mode set → LZW decode → palette → planar blit) prints `LAMUT-OK: adapter=8 296x101`, deterministic at **14,860,944 cycles** headless (56,637,088 with the INT 1Ah 3s hold — tick off the cycle counter, no host clock). **Stage 2 (visual oracle, strategy A):** post-blit plateau at **cycle 14,848,000**; `GET /api/framebuffer?format=index` cropped at (12,49,296×101) is **byte-identical to `tools/lamut-oracle/lamut_0.idx`** (the convention-independent ground truth) — 0 diffs, reproduced across a 2nd run + 2 consecutive captures (deterministic + cycle-neutral pure peek). The frame renders as **kind=1 chained mode-13h** (the overlay drives the chained path; the rasterizer follows the live SEQ chain-4 bit — faithful, the Mode-Y expectation was a prediction not a requirement). RGBA cross-check vs `lamut_0.ppm` = max channel delta 3 (the documented DAC 6→8 convention gap: golden used `c<<2`, zdos uses faithful `(c<<2)|(c>>4)`; index image is the authoritative oracle). `zig build test` green, 476 tests. **P7/P8 committed CI gate deferred:** LAMUT/Vmcode.ovl/BMX/PAL are copyrighted BaK assets (not committable); the faithful path is an out-of-tree-staged, presence-gated black-box test. → `plans/lamut-milestone.md` (RESULT section).
13. **Screenshot PNG API (`GET /api/framebuffer?format=png`)** — a host-side, lossless PNG re-encode of the existing cycle-neutral framebuffer peek (no new emulation, no cycle charge, no device mutation). New module `src/api/png.zig` (module `api`, ABOVE `devices`; NOT in the devices grep-gate, reads no emulated cycle counter, uses no host clock/RNG/float → output is a byte-identical function of the captured frame) encodes with `std.compress.flate.Compress` (`container = .zlib` → the zlib header + Adler32 ARE the IDAT payload) + `std.hash.Crc32` (= the PNG chunk CRC). Chunks: signature, IHDR, PLTE (indexed), IDAT (per-row filter 0/None), IEND. **Color type auto:** indexed (type 3 + 256-entry PLTE built from the DAC via the pinned `expand6to8`, with `pel_mask` applied to indices to match `indexToRgba`) when the mode is paletted — every current rasterizer kind — else truecolor RGB (type 2, alpha dropped). Raw logical resolution (no scaling/aspect/metadata). Reuses the existing `framebuffer_get` worker command; the worker also fills a server-owned 768-byte expanded PLTE slab + `palette_present`/`pel_mask` in the descriptor (all machine reads stay on the worker); the encode runs off-worker on the listener thread over the immutable snapshot into server-owned fixed slabs (`png_out` ~1.3 MiB + 64 KiB flate window + IDAT scratch, allocated once — no per-request alloc, never through `resp_buf`/JSON). `Content-Type: image/png`, `X-Frame-Format: png-indexed|png-rgb`; unsupported mode → 501 (no fake frame). Tests: encoder unit + decompress round-trip (indexed & RGB), `pel_mask`, determinism (two-run byte-identical), the `?format=png` HTTP integration test (mode-13h decode + 501), and the boundary guard. → `plans/screenshot-api.md`.

## Standing invariants (the "why")
Determinism is the prime directive (byte-identical state at cycle N; emulated time = f(cycles), never host clock). The host-serviced trap-stub model is sound (research-validated); input injection is **cycle-keyed, never host-time-keyed**. See `CLAUDE.md`.
